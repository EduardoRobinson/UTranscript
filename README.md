# UTranscript --> Plataforma para transcrição e resumo de video aulas

-Frontend: Angular  
-BackEnd: SpringBoot  
-Microserviços: FastAPI

-LLM para geração de resumo: Phi-4-Mini
-Transcrição: WhisperX
